常见问题

Q：授权失败怎么办？

A：请确认使用付费 Apple 开发者签名的正式版，并在「设置 → 屏幕使用时间」中已开启。

Q：通知收不到？

A：请在「设置 → 通知」中允许本应用通知，并建议开启横幅。

Q：如何取消订阅？

A：打开「设置 → Apple ID → 订阅」，选择「收手吧高级版」取消。年费：中国大陆 ¥68/年，其他地区约 $14.99/年或当地等价货币。

Q：数据会上传吗？

A：不会。设置与统计仅保存在您的设备本地。
